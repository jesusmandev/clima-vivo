# Clima Vivo - Weather App

Una aplicación web dinámica y moderna para visualizar el clima en tiempo real con animaciones impactantes.

## Características

- 🌡️ **Temperatura en tiempo real** - Obtén la temperatura actual de tu ubicación
- 🌍 **Geolocalización automática** - Detecta automáticamente tu ubicación
- 🎨 **Diseño dinámico** - El fondo cambia según las condiciones climáticas
- 🌙 **Modo nocturno** - Interfaz adaptada para la noche
- 🌧️ **Lluvia animada** - Animaciones de lluvia cuando hay precipitación
- 📱 **Responsive** - Funciona perfectamente en dispositivos móviles
- ⚡ **Sin API key requerida** - Usa Open-Meteo API que no requiere autenticación

## Datos mostrados

- Temperatura actual
- Humedad
- Velocidad del viento
- Descripción del clima
- Periodo del día (Día/Noche)

## Uso

1. Abre `index.html` en tu navegador
2. Permite el acceso a tu ubicación
3. ¡Disfruta del clima en tiempo real!

## Tecnologías

- HTML5
- CSS3 (Animaciones y Gradientes)
- JavaScript (Fetch API)
- Open-Meteo API (Datos del clima)

## API

Se utiliza [Open-Meteo](https://open-meteo.com/) - Una API gratuita de clima que no requiere autenticación.
